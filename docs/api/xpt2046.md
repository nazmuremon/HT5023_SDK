# XPT2046 Touch Controller API

**Header:** `#include "ht5023/xpt2046.h"`
**Source:** `lib/ht5023_xpt2046/src/ht5023_xpt2046.c`

---

## Overview

Callback-based driver for the XPT2046 resistive touch controller. Like the
ST7789 driver, all hardware access (SPI byte transfer, CS pin, PENIRQ pin)
is injected through function pointers — the driver does not assume any
specific SPI or GPIO peripheral.

The driver samples X and Y three times and averages them to reduce noise.

---

## Configuration

```c
typedef struct {
    // Required
    ht5023_xpt2046_spi_transfer_byte_fn spi_transfer_byte;
    ht5023_xpt2046_pin_write_fn         cs_write;

    // Optional (pass NULL to skip pen-down detection)
    ht5023_xpt2046_pin_read_fn penirq_read;  // returns true when PENIRQ is high
                                             // (pin is active-low, driver inverts)
    void* user;

    // Optional coordinate mapping (raw ADC → screen pixels)
    uint16_t raw_x_min, raw_x_max;  // calibration: raw ADC range for X
    uint16_t raw_y_min, raw_y_max;  // calibration: raw ADC range for Y
    uint16_t out_width, out_height; // target screen resolution
    bool swap_xy;    // swap X and Y axes (for landscape/portrait)
    bool invert_x;   // mirror the X axis
    bool invert_y;   // mirror the Y axis
} ht5023_xpt2046_config_t;
```

**Callback signatures:**

```c
typedef uint8_t (*ht5023_xpt2046_spi_transfer_byte_fn)(uint8_t tx, void* user);
typedef void    (*ht5023_xpt2046_pin_write_fn)(bool high, void* user);
typedef bool    (*ht5023_xpt2046_pin_read_fn)(void* user);
```

---

## Output types

```c
typedef struct {
    bool touched;
    uint16_t x_raw;   // raw 12-bit X ADC (0–4095)
    uint16_t y_raw;   // raw 12-bit Y ADC (0–4095)
    uint16_t z1_raw;  // raw pressure sample Z1
    uint16_t z2_raw;  // raw pressure sample Z2
} ht5023_xpt2046_raw_sample_t;

typedef struct {
    bool touched;
    uint16_t x;  // mapped screen X coordinate
    uint16_t y;  // mapped screen Y coordinate
} ht5023_xpt2046_point_t;
```

## Functions

### `ht5023_xpt2046_init`

```c
bool ht5023_xpt2046_init(ht5023_xpt2046_t* touch,
                          const ht5023_xpt2046_config_t* cfg);
```

Copy the configuration and assert CS high (idle state). Returns `false` if
`touch` or `cfg` is NULL, or if the required callbacks are NULL.

---

### `ht5023_xpt2046_pen_is_down`

```c
bool ht5023_xpt2046_pen_is_down(const ht5023_xpt2046_t* touch);
```

Returns `true` if the PENIRQ pin is low (touch detected). If `penirq_read`
was not provided, always returns `true` (sample unconditionally).

---

### `ht5023_xpt2046_read_channel_raw`

```c
uint16_t ht5023_xpt2046_read_channel_raw(const ht5023_xpt2046_t* touch,
                                          uint8_t command);
```

Send a command byte and clock out 2 response bytes. Returns the 12-bit ADC
result. Drives CS low and high around the transaction.

Predefined command bytes (from the XPT2046 datasheet):

| Command | Channel |
|---------|---------|
| `0x90` | Y position |
| `0xD0` | X position |
| `0xB0` | Z1 pressure |
| `0xC0` | Z2 pressure |

---

### `ht5023_xpt2046_read_raw_sample`

```c
bool ht5023_xpt2046_read_raw_sample(const ht5023_xpt2046_t* touch,
                                     ht5023_xpt2046_raw_sample_t* out);
```

Check pen-down, then take 3 X + 3 Y samples, average them, and read Z1/Z2.
Applies a basic pressure filter (`z1 > 20`).

Returns `true` if a valid touch is detected, `false` otherwise.

---

### `ht5023_xpt2046_read_point`

```c
bool ht5023_xpt2046_read_point(const ht5023_xpt2046_t* touch,
                                ht5023_xpt2046_point_t* out);
```

High-level function: calls `read_raw_sample`, then maps the raw coordinates
to screen pixels using the calibration values in `cfg`. If
`out_width`/`out_height` are 0 or the raw range is invalid, the raw ADC
values are returned unchanged.

---

## Calibration

The raw ADC values for the screen corners must be measured empirically.
Typical values for a 240×240 IPS panel:

```c
.raw_x_min = 200,  .raw_x_max = 3900,
.raw_y_min = 200,  .raw_y_max = 3900,
.out_width  = 240, .out_height = 240,
```

Override at build time:
```bash
make EXAMPLE=xpt2046_touch_demo \
     CFLAGS="-DTOUCH_RAW_X_MIN=300 -DTOUCH_RAW_X_MAX=3800"
```

## Example

```c
#include "ht5023/xpt2046.h"
#include "ht5023/spi.h"

static uint8_t spi_cb(uint8_t tx, void* u) {
    (void)u; return ht5023_spi_transfer_byte(tx);
}
static void cs_cb(bool high, void* u) {
    (void)u; gpio_write(PA3, high);
}

ht5023_xpt2046_t touch;
const ht5023_xpt2046_config_t touch_cfg = {
    .spi_transfer_byte = spi_cb,
    .cs_write = cs_cb,
    .raw_x_min = 200, .raw_x_max = 3900,
    .raw_y_min = 200, .raw_y_max = 3900,
    .out_width = 240, .out_height = 240,
};

ht5023_xpt2046_init(&touch, &touch_cfg);

ht5023_xpt2046_point_t pt;
if (ht5023_xpt2046_read_point(&touch, &pt)) {
    // pt.x, pt.y contain the mapped screen coordinates
}
```
